数据与自动更新说明：① 岗位库(site/data/jobs.json)为人工核实的结构化数据，每条来自企业官网/官方招聘平台公告(种子数据：2026-09-05 核实)；② 官方公告动态(site/data/announcements.json)由 GitHub Actions 每天自动抓取国务院国资委官网「央企招聘」栏目(www.sasac.gov.cn)生成并推送到本站。
为什么岗位卡不能"全自动解析"：企业官网普遍为动态页面或带反爬(电信官网对程序返回 412、国家电网需安全验证)，程序无法稳定读懂每家报名页。报名截止、专业方向、港澳学历适用性等关键字段仍需按官方公告人工核实后维护进 jobs.json——不做机器臆断，这是信息可靠性的底线。
提示：收藏与专业档案仅保存在本机浏览器(localStorage)；报名一律通过卡片内官方链接，谨防收费骗局。
